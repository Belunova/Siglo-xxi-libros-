# Siglo XXI Libros — Mockups y documentación técnica

Proyecto NOVAH para Librería Siglo XXI (Córdoba, Argentina).

## Archivos

| Archivo | Qué es |
|---|---|
| `ecommerce-completo.html` | Tienda online — Home, Catálogo, Ficha de producto, Carrito/Pago, Mis pedidos (5 pestañas) |
| `panel-interno.html` | Panel de la vendedora — Socias/préstamos, Pedidos/stock, Ventas (3 pestañas) |
| `cuenta-socia.html` | Vista de "Mi cuenta" para socias — Chequera, Sellos, Mis pedidos |
| `integraciones-visual.html` | Infografía de arquitectura e integraciones, para mostrarle a la clienta |
| `stack-y-costos.md` | Documentación de arquitectura, stack tecnológico y costos estimados |
| `home-visitante.html`, `catalogo-standalone.html`, `ficha-producto-standalone.html` | Versiones sueltas de pantallas individuales (versiones previas a la consolidación en `ecommerce-completo.html`) |

## Stack técnico

WordPress + WooCommerce (tienda) · Airtable (catálogo maestro, panel interno) · Make (automatizaciones) · Mercado Pago (pagos) · Google Books API (portadas/sinopsis).

Ver `stack-y-costos.md` para el detalle completo.
